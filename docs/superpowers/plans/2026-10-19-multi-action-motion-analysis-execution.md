# 多动作与多机位分析实施记录

日期：2026-10-19。对应设计：`docs/superpowers/specs/2026-10-19-multi-action-motion-analysis-design.md`。

## 已落地的软件能力

- 动作分析内的动作库可搜索，并按器械、部位和类别筛选。四个基础动作有稳定 ID、独立周期、关键点与轨迹目标、候选质量观察以及逐机位能力说明。未知动作 ID 不会被静默认成卧推；旧项目缺失动作 ID 时按历史侧面卧推读取。
- 用户可从动作详情预选动作进入导入或拍摄，也可从媒体入口进入后再确认动作与机位。未开放机位的自动分析被禁用，实验性能力在界面明确标示。
- 卧推保留现有近侧杠铃片手动标记与跟踪流程。深蹲、硬拉、引体向上使用姿态关键点生成实验性重复候选和人体轨迹，缺失关键点时断段；人体点不被标记为杠铃位置。所有自动次数要求人工核对。质量观察在存储和界面中为 `unknown/not_validated`，记录动作版本、机位、时间段和所需关键点，不输出未验证的姿势结论。
- 项目载荷 v3 支持多个独立观察片段，片段各有媒体、结果、机位和重复。可加入导入视频或拍摄片段、切换、单独移除。项目顶层继续保存当前结果，旧 v1/v2 结果可读；清理器保留项目内所有片段引用。训练组关联、删除组后保留项目以及训练 JSON 备份边界沿用既有规则。
- 综合视图按机位列出候选次数；数量不同时显示冲突。没有可靠的跨视频重复对应证据，因此不自动匹配第 N 次，也不叠加不同坐标系轨迹。

## 尚需数据与设备验证

四个动作各机位的计数误差、边界误差、人体/器械轨迹误差和质量观察精确率/召回率均没有授权标注样本，不能标成已验证。深蹲、硬拉和引体向上的实验性候选次数只做了合成时序及缺失区间软件测试，未做真实视频准确度验收。卧推之外尚无已验证杠铃检测器；多视频的同步或重复匹配仍待专门数据与规则验证。真实 Android 摄像头、机位切换、功耗和性能也未在设备上验收。
