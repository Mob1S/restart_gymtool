# 卧推视频复盘实施记录

日期：2026-10-19。状态：Android 实验版代码与安装包已交付；真实卧推素材、真实设备运行和准确率验收未执行。

## 已实现

- 「本场已记」与历史详情的已完成组提供视频复盘入口，每组关联一项；支持自建动作，无名称自动猜测。
- 本地视频副本进入 Android `noBackupFilesDir`，选择最长 3 分钟片段，手动标记近侧杠铃片中心及追踪区域。不会上传或删除相册原视频。
- MediaExtractor / MediaCodec 按实际呈现时间戳解码，处理旋转及 YUV stride；OpenCV 4.12.0 局部特征前后向光流独立追踪杠铃片。
- 内置 MediaPipe Tasks Vision 0.10.32 与 Pose Landmarker Lite float16/1。模型 5,777,746 字节，SHA-256 为 `59929e1d1ee95287735ddd833b19cf4ac46d29bc7afddbbf6753c459690d574a`。官方模型卡声明 Apache-2.0，许可证随资源提供。
- 视频慢放、按源帧时间戳逐帧查看、轨迹与骨架开关、多次轨迹平移叠加、同侧二维肘角参考。人工重新定位会要求重新分析后才能保存，避免新标记与旧结果混存。
- 自动分次、人工增删次数与编辑起止/底部边界；下降、底部停顿、推起时间和组内相对幅度。缺口不连线，包含缺口的指标不可计算；记录次数与视觉次数独立。
- SQLite schema 9 新增 `video_review`，组删除级联清除关联；文件在启动、数据变更和退出时清理，编辑中目录受保护。失败重算保留旧结果，旧结果文件在离开编辑后清理。
- 训练 JSON 备份契约仍为 v6 / schema 8，不携带复盘私有路径。恢复提示本地复盘会清除，事务失败可回滚复盘关联，原训练数据保持完整。
- Web 显示 Android 能力限制，原训练功能继续可用。

## 安装包

- 路径：`build/app/outputs/flutter-apk/app-release.apk`。
- 构建命令：`flutter build apk --release --no-pub --target-platform android-arm64`。
- 文件大小：159,647,775 字节，约 152.3 MiB。模型本体约 5.5 MiB；视觉运行库显著增加包体，后续可继续按 ABI 分包优化。
- APK SHA-256：`0560ccb2bfb7a9e51635d2a08612170a503f9842cc538bb4cef24c4f823fa788`。
- ZIP 检查确认模型和许可证存在。`--target-platform android-arm64` 限定了 Flutter 运行时，但上游 AAR 仍携带其他 ABI 的视觉库，因此此包仅交付 ARM64 设备使用；真正按 ABI 拆分仍可进一步缩小体积。
- 主应用包名仍为 `com.mobis.gym_tracker`，未安装到用户手机，未生成独立验收应用。

## 明确边界

- 用户说明暂时没有真实卧推视频，并授权先继续开发；ADB 未发现连接设备。因此不能宣称实际视频可准确识别、遮挡可可靠恢复、达到某个 FPS 或处理速度。
- 模块界面标记为实验性。首次真实验收仍需按设计文档 §9 检查位置误差、分次边界、追丢与背景误跟踪、旋转及变帧率、模型初始化、离线运行和取消/重启。
- 未保存的新导入/分析只在当前编辑会话持有，进程中断后需重新导入；已保存项目可重新打开并重分析。尚未实现持久化的分析任务断点续跑，这是相对最初设计的收敛。
- 本轮未做设备屏幕视觉验收；页面测试使用模拟媒体/推理结果，只验证交互和数据保护，不作为模型效果证据。
- 本轮不实现绝对杠速、厘米位移、综合动作评分、两侧对称或肩胛判定。
