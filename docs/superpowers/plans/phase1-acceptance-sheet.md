## 2. 六项验收，逐条走

### ✅ 第 1 项：一组做完到记录完成 ≤ 2 次点击

**判据**：记一组只需要点两下，且全程不用手动输数字。

1. 首页点「开始训练」
2. 空训练态点「**＋ 添加动作**」→ 弹层里选「深蹲」
3. 看记录页：大数字应该是 **20**，下面写「第 1 / 1 组」
4. 点底部「**✓ 完成这组**」← **第 1 次点击**
5. 切到休息界面，点「**开始第 2 组**」← **第 2 次点击**
6. 回到记录页，应该显示「第 2 / 2 组」，数字还是 20（预填了上一组）

**通过标准**：第 4、5 步各点一下就够，中间没有要求你打字。
**额外试一下**：手指按住大数字上下拖动 —— 应该能连续变值（不用一下下点加减）。

---

### ✅ 第 2 项：记录过程不打断节奏

四条各自独立，逐条打勾：

- [ ] **屏幕常亮**：停在记录页，把手机放下别碰，等超过你手机的自动锁屏时间
      （通常 30 秒～1 分钟）—— 屏幕**不应该**自己暗下去或锁屏
- [ ] **震动反馈**：点「✓ 完成这组」时手上有一下轻微震动
- [ ] **正计时不催促**：休息界面是在**往上数**（00:01、00:02…），
      不是往下倒数、也没有「还剩几秒」的催促
- [ ] **换动作不用退出**：顶部那排动作条能点，点「＋」能再加动作

> **第 1 条是旧项目专门要过的关**。它是 `wakelock_plus` 在工作 ——
> 若屏幕照样自动锁了，就是它没生效，**这是要记的问题**。

---

### ✅ 第 3 项 ⭐：训练记录永不丢失（**本项最重要**）

**这两条是 Phase 1 全部价值的所在，请务必都做。**

**3a. 强杀后能恢复**

1. 开一场训练，加一个动作，**完成 3 组**
2. **强杀 App**（从最近任务列表划掉，或 `adb shell am force-stop com.mobis.gym_tracker`）
3. 重新打开
4. **期望**：首页出现「**继续 今天 HH:MM 的训练**」卡片
5. 点进去 —— **期望**：已经完成的组数还在（显示「第 4 / 4 组」），不是从零开始

**3b. 息屏挂起后计时仍然准确**

1. 完成一组，进入休息界面，**记下当前读数**（比如 `00:12`）
2. 按电源键**息屏**，心里默数或看表**等 35 秒左右**
3. 亮屏，回到 App
4. **期望**：读数应该**也往前走**了差不多 35 秒（比如 `00:47` 左右）

> **这一条证明的是**：计时基于 `rest_started_at` 时间戳现算，
> 而不是一个累加的计数器 —— 后者在系统挂起 App 时会**冻住不动**。
> 旧项目真机实测：息屏前 18:20 → 息屏 35 秒后 19:01（Δ41 秒 vs 实测等待 40 秒）。
>
> **读数差和实际等待时间对不上（差得远，比如只走了 2 秒），就是没通过。**

**记录这两行**：

| | 你的读数 |
|---|---|
| 息屏前 | |
| 等了多久 | |
| 亮屏后 | |
| 差值 vs 等待 | |

### ✅ 第 4 项：总结页

先在深蹲上完成 **3 组**（每组 20kg × 8 次），然后点右上角「结束训练」。

- [ ] 顶部三个数字：**时长 / 总组数 / 总容量**
- [ ] 「总容量」下方写着「**总容量（重量 × 次数）**」
      —— 这是口径要求，**不该**写成「个人最好」
- [ ] 卡片第一行是**原始次数数组**（比如 `8 / 8 / 8`），不是「稳定」之类的结论
- [ ] 区块标题是「组间休息回顾（**粗略参考**）」
- [ ] 深蹲那张卡有提示文案

**手工核算**（这一步不能省，数字对不对只能自己算）：

```
3 组 × (20 kg × 8 次) = ______ kg
```
屏幕显示的总容量应该是这个数。

**再验一次「少于 3 组时沉默」**：只完成 **1 组**就结束训练 ——
那张卡应该显示「**组数不足 3 组，暂不判断**」，而不是硬给一条建议。

### ✅ 第 5 项：数据落地检查

**5a. 结束训练后**

- [ ] 点总结页的「完成」回到训练页
- [ ] 首页**不再**显示「继续上次训练」，只剩「开始训练」
- [ ] 把 App 从最近任务划掉重开 —— 仍然只有「开始训练」（没有残留的进行中训练）

**5b. 从零建库**

1. 系统设置 → 应用 → `gym_tracker` → 存储 → **清除数据**
   （或 `adb shell pm clear com.mobis.gym_tracker`）
2. 重新打开 App
3. **期望**：不崩、不白屏，能正常进到首页
4. 点「开始训练」→「＋ 添加动作」——
   **期望**：弹层里能看到动作列表，且**胸在最上面**（俯卧撑、器械推胸、上斜卧推…）

> 第 4 步是在验「52 个预置动作真的写进去了」。
> 顺带看**排序**：胸组里应是 俯卧撑(fu) → 器械推胸(qi) → 上斜卧推(shang) → 绳索夹胸(sheng)
> —— 这是**拼音序**；如果排成「上斜、下斜、卧推、俯卧撑」那种，就是退回了按 Unicode 排。

## 3. 遇到问题怎么记

每条记三样就够：**在哪一步** + **你期望什么** + **实际看到什么**。
能截图最好。

**特别值得记的**（这些都是「只有真机会暴露」的类别，是我最想知道答案的）：

- 屏幕没有保持常亮
- 息屏后计时不走了 / 走少了
- 有任何一屏被**状态栏或底部导航栏**压住
- **按返回键**时行为怪（比如从记录页按返回直接退出 App、
  或者卡在某一页出不来）
- 中文显示成方块 / 数字没有等宽（拖大数字时整块在抖）
- 卡顿、掉帧、或任何一处点下去没反应
