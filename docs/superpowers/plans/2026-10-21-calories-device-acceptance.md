## 建议顺序及预期结果

1. **升级与导航**：覆盖安装后，原训练、计划、历史与动作分析项目仍在。底栏依次为训练／热量／动作分析／历史／进步；五个主页的右上角设置均可返回原页。饮料录入、核对和趋势使用独立页面。
2. **包装饮料**：热量 → 记录饮料 → 手动添加。名称“验收可乐”，每份体积 `330` mL、能量 `42` kcal、基准每 100 mL、来源包装标签。记录一份显示 **138.6 kcal**；半份 **69.3 kcal**，两份 **277.2 kcal**，250 mL **105 kcal**。保存一次只新增一条，可从成功提示撤销。
3. **kJ、零与未知**：180 kJ／100 mL，330 mL 显示 **142 kcal**。明确输入 0 可以显示 0 kcal；留空热量应显示待补热量，不能变成零。全空日期显示“尚未记录”，有未知项时合计注明未计入数量。
4. **拍照与选图**：分别拍摄、导入清晰的实际中文营养标签。查看原图、识别文字、数值、单位与基准；核对后才能保存。横放、反光和小字应重点检查。每 100 g、多个能量值、缺失单位或基准不能自动生成数值。取消识别或返回不写入饮料库和记录；拒绝相机权限后仍可选图。相机临时文件和原图不进入 JSON 备份。
5. **现制饮品**：保存杯型、糖度、加料和冷热信息；没有每份体积时，只使用份数，不能按杯型名称换算 mL。修改配置后原能量被清除，需要重新核对；不能把三分糖直接算作全杯热量的 30%。
6. **个人库与快照**：收藏／取消收藏、同名不同规格并存；编辑库条目能量不改变已保存的历史。归档从常喝入口移除，历史保留，管理库可查看并恢复归档条目。历史记录可单独修正当时热量依据。
7. **补记、修改与删除**：选择昨天补记；修改发生时间至另一日期，记录随之移动。删除前有确认，合计和 7／30 天趋势更新。跨午夜、重启后，已保存记录仍归属原来的本地日期。
8. **离线与搜索**：飞行模式下使用个人库、新建、修改、删除并重启应用，记录应保留。恢复网络搜索“coca cola”和“可乐”；公共结果显示实际品牌和规格，选择后核对资料。服务超时、断网、无结果要显示不同状态，不用假结果替代。公共资料仍属于公共数据库来源。
9. **备份与恢复**：导出 v7 / schema 11，核对预览中的训练、饮料库及饮用记录数量。恢复 v7 会替换对应数据；使用刚导出的同一份备份验证往返。若有旧 v1–v6 备份，可核对预览明确说明保留本机饮料。恢复包含训练、动作和计划的替换操作，请使用已确认的验收文件。
10. **主题、字体与回归**：深浅主题、系统大字体、横屏及弹出键盘时，按钮和数值可达且不溢出；开启减少动态效果。开始训练、完成组、休息、结束训练、查看历史与进步、管理计划和动作分析仍可操作。
