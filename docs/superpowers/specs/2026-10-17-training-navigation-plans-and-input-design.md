# 训练首页、历史入口、多天计划与重量输入设计

日期：2026-10-17。状态：用户以“go on”确认整体设计，已进入实施计划编写；尚未修改应用代码。

## 1. 目标与依据

让训练页围绕开始训练、选择本次计划和训练日展开；历史页统一处理记录的查看、补加和删除；记录页用方向明确的滑动完成重量、次数调整，并支持不同器械的重量单位。

用户已逐项确认：

- 采用 B 方案，训练首页默认展示月历，“开始训练”保持在训练内容区域中间。
- 计划不能固定成三分化。每套计划包含多个训练日，每个训练日独立配置动作；名称、天数、动作组合由用户决定。
- 删除首页计划区右上角重复的新建入口，仅在“管理计划”内提供“新建计划”。
- 训练日顺序轮换，同时允许手动选择；每套计划分别计算进度，完成整次训练后推荐下一日，中途退出不推进。
- 按起手区域锁定调整对象：重量上下滑动，次数左右滑动；对应数值高亮，跨区域或斜滑均不切换对象，松手后解锁。
- 去掉记录页重量、次数旁的两对加减按钮。
- 调重幅度点击后打开选项供直接选择，不能每点击一次就轮换数值。
- 支持 kg 和 lb；主数值跟随器械单位及实际读数，用户可选择显示换算后的 kg。
- 单位和调重幅度按每个动作分别记住。
- 点击月历日期跳到历史页并定位当天，查看、补加和删除集中在历史页。

本稿也明确了实现必需的默认行为，尤其是滑动灵敏度、手势中断、空计划和旧数据迁移；这些默认行为随本稿一起审阅。

## 2. 页面与导航

### 2.1 训练首页

从上到下为页面标题、月历、居中的主按钮与本次训练说明、底部计划卡片，再接应用底部导航。

主按钮的中心对齐可用训练内容区域的垂直中心，不把系统状态栏、底部导航计入内容区域。月历日期行数及计划数量变化不能把按钮挤走。手机窄屏、横屏和大字号导致内容无法同时容纳时，允许整页滚动并保证控件可达，避免裁切、遮挡；常规手机竖屏保持居中布局。

- 月历默认当前本地月份，可切换月份并回到本月；按本地日期标记今天。
- 圆点表示当天存在已完成训练。一天有多次训练时仍用一个标记；删除当天最后一场训练后去掉标记。
- 点击任意有效日期进入该日期的历史列表；当天无记录时显示可补加的空状态。
- 点击日期只用于浏览记录，不改变本次计划、训练日或新训练的开始日期。
- 有进行中训练时，主操作优先显示“继续训练”，沿用现有活动训练冲突处理，不新建第二场。

计划卡片显示“计划名称／共有几个训练日”“本次训练日”“动作摘要”，提供“切换计划”“选择训练日”“管理计划”。长名称允许换行，动作摘要可截断。完整计划列表在选择界面展示，首页不铺开所有计划。

没有计划时仍可自由训练；没有训练日的计划提示进入管理页配置，不能伪装成已有一个训练日。提供独立的自由训练选择，避免用户为临时训练删除计划。

### 2.2 历史页

历史页右上角提供“补加”，记录行提供删除操作；原有详情页仍可进入。删除使用现有确认流程，显示日期和受影响的训练信息，成功后同时更新历史、进步与月历标记。

从月历进入时使用显式日期参数，例如 `/history?date=2026-10-16`，仅显示所选本地日期的记录，并展示日期提示和“查看全部”。选择“查看全部”后恢复全部历史；从详情返回保留此前的日期定位。

日期归属与现有历史一致，按训练的本地开始日期分组；查询范围使用该本地日期起点至次日本地日期起点，不能简单增加固定 24 小时。

补加表单沿用现有手动录入和预览流程。从日期定位状态进入时预填该日期，普通历史入口默认今天；用户仍可修改日期。保存后显示新记录实际所属日期，避免记录已保存却在当前筛选中不可见。取消不产生记录。

手动补加作为主入口；CSV 导入作为历史页的次级“导入记录”入口，复用原有流程。设置页移除记录导入和训练计划管理的入口，保留主题、备份等设置功能。原导入和计划路由继续可用，不因入口迁移造成导航失效。

## 3. 计划、训练日与轮换

### 3.1 数据含义

计划是整套训练安排，训练日才是一次开训使用的动作清单。例如“力量进阶”包含上肢 A、下肢 A、上肢 B、下肢 B；“全身基础”可以只有全身 A、全身 B。UI 不按名称推断分化，不设固定的三个槽位，也不把训练日绑定到星期。

计划、训练日、训练日中的动作项均有稳定 ID 和顺序。相同动作可在不同训练日出现；每次出现的清单项独立标识，复用动作库的动作定义。计划不增加目标重量、目标次数或周期排课。

管理路径为：训练首页 → 管理计划 → 新建／编辑计划 → 管理训练日 → 编辑当日动作。可以更名、增删和调整训练日顺序；当日动作复用现有多选、排序与删除交互。未来模板作为可选的计划创建来源接入，本期不内置固定分化模板。

编辑使用本地草稿，点击保存才原子提交；取消不留下新建空壳，脏草稿离开时使用现有丢弃确认。允许保存尚未配置训练日的计划和空动作训练日；前者引导配置，后者在明确选择后可开始空训练并添加动作。

删除整套计划或训练日需明确确认。保留已经产生的训练、动作、组和名称快照，仅解除失效的计划关联。已经开始的训练使用开训时复制的动作清单，编辑模板不重写它。

### 3.2 推荐规则

当前计划独立推荐训练日，切换计划不影响另一计划的进度。优先使用用户本次手动选择；否则根据该计划最近一场符合条件的已完成训练，推荐其训练日的下一日，末尾回到首日。

选中的父计划记为本机偏好，重新打开应用仍选择它；首次进入或该计划已删除时选择当前列表首项，无计划时进入自由训练。本次手选训练日用于即将开始的训练，不另存轮换游标；尚未开训就重新启动应用时，恢复该计划的推荐训练日。

| 情况 | 行为 |
| --- | --- |
| 计划尚无关联的已完成训练 | 推荐首个训练日 |
| 完成某训练日的一整次训练 | 下次推荐该日之后的一日 |
| 仅完成一组、休息、退出或继续训练 | 不推进 |
| 手动选择另一训练日但未完成 | 不改变长期推荐依据 |
| 手动选择并完成整次训练 | 从实际完成的训练日继续轮换 |
| 自由训练、手动补加或 CSV 导入 | 不推进计划轮换 |
| 删除最近一次关联训练 | 根据剩余有效完成记录重新推荐 |
| 最近来源训练日已删除 | 回到该计划首个训练日 |
| 训练日顺序发生调整 | 按当前顺序寻找实际完成日的下一日 |

不另存容易失配的全局下标。完成关联的空动作训练也沿用现有完成语义计入轮换。开训时在一个事务里验证选择、建立 session、复制训练日动作，并记录计划和训练日来源；写入失败不改变推荐。

## 4. 重量与次数手势

### 4.1 方向与锁定

| 起手区域 | 有效方向 | 数值变化 | 忽略方向 |
| --- | --- | --- | --- |
| 重量 | 上／下 | 增重／减重，按当前动作步长 | 水平 |
| 次数 | 右／左 | 增加／减少，每档 1 次 | 垂直 |

按下时锁定对象，对应数字高亮，另一数字弱化。以起手位置和起始数值计算累计位移，不在跨区域时重新命中；多点触摸期间仅处理最初持有锁的指针。滑动不能同时触发页面滚动、动作切换或完成按钮。

本稿默认重量每 16 个逻辑像素一档，次数每 24 个逻辑像素一档；不足一档不变更。没有惯性或速度加成；返回到起手位置则返回起始值。正常松手保留当前值并解除高亮。

系统取消、指针捕获丢失或页面在拖动中离开时，恢复本次拖动的起始值并释放锁；未松手时不能完成该组或修改单位、步长。写入沿用现有串行和冲突控制，不让迟到的拖动写入覆盖完成后的组。

默认重量下限为 0、上限沿用等效 500 kg；次数范围沿用 0–100。历史导入的超范围原值保留，允许向有效区间修正，不因一次触摸被强制截断。到达边界后反向调节正常生效。

移除两对可见的加减按钮，同时保留键盘和读屏的增减语义：重量使用上下键，次数使用左右键，不要求用户必须完成拖动才能录入。

### 4.2 幅度选择

点击“幅度 … ▾”打开当前动作的调重与单位面板，展示当前选项的选中态。选择选项仅修改面板草稿；点击“确认”后生效并保存，取消或返回不修改数值及偏好。

- kg 常用幅度：0.5、1、1.25、2.5、5、10。
- lb 常用幅度：1、2.5、5、10、20。
- 同时支持输入正的有限自定义幅度。空值、0、负数和非有限数显示就地错误，不提交。
- 按动作保存首选单位，并分别记住 kg、lb 的步长。新动作默认 kg、2.5 kg；首次使用 lb 默认 5 lb。

## 5. 器械读数、单位与换算

主数值是用户正在填写的器械读数，与 kg／lb 单位一起组成完整重量。选择器械单位时保留正在填写的数值，例如 40 kg 的输入改选 lb 后成为 40 lb，不自动变为 88.18 lb。这个操作用于确认当前器械标注，区别于辅助换算。

按步长计算主数值，不通过保留两位小数的 kg 中间值回推。整数显示 50，不显示 50.00；2.5 lb 步长可以产生 52.5 lb；1.25 等实际设置保留必要的小数，不为界面统一格式补零。

lb 模式提供“同时显示换算后的 kg”，默认关闭，按动作记住选择。开启后在主数值下方展示参考值，例如 50 lb → `≈ 22.68 kg`、100 lb → `≈ 45.36 kg`。该行保留两位小数，不参与滑动命中，不改变主数值和步长。

换算使用 1 lb = 0.45359237 kg。存储保留原始器械读数和原单位，另计算未按显示位数舍入的标准 kg 重量，供现有容量、进步和 1RM 计算使用。展示舍入不参与统计计算。

单位偏好只作用于当前待填组和后续录入。已完成组、历史、上一组提示和休息页“刚完成”读取该组保存的单位，不能因为后来切换了动作偏好而改写过去的器械读数。编辑历史组时显式显示原单位；手动补加同样支持组重量单位，避免所有补记被误认为 kg。

加载上一组或上次表现时，优先使用当前动作首选单位下的最近一次原始读数；没有同单位记录时使用该单位的初始值（20 kg 或 45 lb）。不把另一单位的历史换算成不符合器械刻度的默认主数值；跨单位的历史仍可作为明确标记的参考值展示。

## 6. 与现有代码的衔接

当前基线为 `bd1b09f`，数据库 schema 5、备份版本 3。现有 `SplitTemplate`／`split_template` 只有有序动作清单，`session.template_id` 参与现有轮换；它对应新设计中的训练日，不能只换页面名称来假装支持多天计划。

| 边界 | 职责及依赖 |
| --- | --- |
| 首页／日历 | 显示月度完成情况、本次计划和训练日；使用仓储查询和导航参数，不计算组统计 |
| 历史页 | 消费日期筛选参数，调用已有补加／删除流程，订阅 DataRevision |
| 计划仓储与 controller | 保存父计划、训练日、动作顺序与编辑草稿，原子开训；依赖已有 SqlExecutor |
| 轮换领域逻辑 | 根据一个计划的当前训练日顺序和完成来源计算推荐，独立于 UI |
| 重量值与格式化逻辑 | 明确原单位、原始读数和标准 kg，集中换算和格式化规则 |
| 输入组件 | 管理起手锁定、方向与高亮，向记录页输出器械单位下的数值 |
| 偏好仓储与 controller | 保存每个动作的单位、各单位步长及换算展示偏好 |
| 备份／导入 | 保留计划层级和单位信息，校验后事务写入，兼容旧版 |

扩展现有文件与职责，不引入第二套动作库、重复统计算法或第二套活动训练状态。

### 6.1 迁移策略

增加父计划实体，并将现有模板作为训练日归入一套默认的“我的训练计划”，保持原模板 ID、名称、动作和先后顺序；已有上肢／下肢等模板不会被迁移成多个互不相关的单日父计划。没有旧模板时不生成空的示例计划。

原 `session.template_id` 继续识别来源训练日，补充父计划关联和开训时的计划／训练日名称快照。旧记录仍保持原名称；仅在来源可确认时补充关联，不猜测已删除模板的含义。

旧组记录和 CSV 中未注明单位的重量仍按原有 kg 语义读取；新增 lb 记录同时带原始读数、原单位和标准 kg。旧动作偏好的 kg 步长原样保留，新增 lb 步长采用默认值。扩大原有仅允许五种步长的存储校验，接受面板支持的正有限自定义值。

增加新的向前迁移，目标 schema 6、备份版本 4；不重写已发布迁移。备份覆盖父计划、训练日、会话来源、重量原值和单位以及动作偏好。新版读取旧备份时执行同样的层级和默认值升级；旧格式不具有的来源不能凭空恢复。导出 CSV 显式包含原单位与标准 kg，既保留器械读数，也提供统计口径。

### 6.2 错误与一致性

计划保存、删除、开训、组写入与导入使用现有事务和版本冲突检查。失败时保留可重试草稿，不显示已成功的轮换结果。每次成功提交发出一次 DataRevision，统一刷新首页、历史、进步和活动训练。

路由日期非法时显示普通历史列表并提示日期无效，不解析成错误日期。历史删除仍针对明确 session ID；月历日期定位不能把删除误扩大到当天全部记录。

## 7. 验收

1. 常规手机竖屏中月历完整、主按钮居中、计划卡片不遮挡；窄屏和大字号所有操作可达。
2. 月历有记录和无记录日期都能正确进入历史筛选；返回详情保留日期；补加预填、修改日期、取消和查看全部均正确。
3. 同一天多场训练、跨本地午夜与夏令时边界的分组正确；增删记录后日历标记和统计同步。
4. 0／1／多个计划、各自不同训练日数及长名称可操作；新建仅从管理页进入。
5. 编辑一个训练日不改另一日；排序、删除、草稿取消、旧模板迁移和备份恢复保持原动作与记录。
6. 手动选择、只完成一组、中途退出、继续训练、完成整场、切换计划、删除最近训练和自由训练符合轮换表。
7. 实际触摸测试覆盖斜滑、跨区、多指、系统取消、边界反向、松手、完成组与写入竞争；键盘和读屏同样可调数值。
8. 幅度选择打开不改值，取消不改值，确认才生效；非法自定义幅度被拒绝，各动作及各单位偏好互不覆盖。
9. lb 主数值按器械步长变化；40 lb 加 10 得到 50 lb，50 lb 加 2.5 得到 52.5 lb，不出现 kg 回算产生的 88.18 等默认刻度。
10. 关闭 kg 参考不影响原始重量与统计；50 lb 参考为约 22.68 kg，容量计算使用未舍入换算值。
11. 已完成组保留原单位，后续改变偏好不改历史；编辑、上一组、休息、补加、CSV、备份恢复均保留单位语义。
12. 回归原有完成组编辑／撤销、动作多选／临时替换、串行待填重量、计划原子开训和备份还原。
